## 🔎 Project Introduction – BlueTrace

**BlueTrace** is a SOC-focused detection and log-analysis project built to simulate and investigate a real-world SSH brute-force attack in a controlled lab environment.
Using Kali Linux and Ubuntu Server, I analyzed authentication logs to trace attacker behavior, identify suspicious login patterns, and validate evidence integrity through hashing. 
The project demonstrates practical SOC L1/L2 skills including log investigation, attack detection, incident documentation, and structured forensic workflow from a Blue Team perspective.
